# 机甲突袭 · 回响 / MECH STRIKE · ECHO

单人生存类 roguelike 网页游戏。选择驾驶员、主武器与机甲，穿越五个战区，每区十四波敌潮后挑战关底首领；通关后解锁无尽爬塔。

- 在线游玩：https://surtr42u.github.io/mech-strike-echo/
- 技术栈：原生 JavaScript + Canvas 2D + Three.js（场景壳），零构建、零依赖安装
- 存档：浏览器 `localStorage`（键 `mr_prof_v2`），被禁用时回退 cookie

## 本地运行

`dist/` 是完整可运行目录，直接用任意静态服务器打开即可：

```bash
cd dist
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

不要用 `file://` 直接打开：贴图与字体按相对路径加载，需要 HTTP 环境。

## 目录

```
dist/
├─ index.html         # 25 个 <script defer>，顺序即依赖声明
├─ game.js            # 主循环、渲染、武器/皮肤/Boss 数据表（约 9.5k 行）
├─ campaign.js        # 战役波次、敌人编成、难度开关与自适应难度
├─ hexes.js           # 海克斯卡池、选牌计划、质变/升彩
├─ talents.js         # 普通强化与海克斯选择界面
├─ growth.js          # 补给站永久模块、技能槽
├─ preparations.js    # 战前准备（选牌/护盾/赏金/拾荒等）
├─ weapon-attachments.js # 武器配件收藏、三槽装配与战斗掉落
├─ endless.js         # 无尽塔
├─ manifest.webmanifest # 添加到主屏幕 / 独立窗口运行
├─ sw.js              # 轻量离线壳（网络优先）
├─ …                  # 其余为场景、地图、弹道、Boss 等模块
├─ assets/            # 贴图、字体
└─ vendor/            # three.min.js
```

新增模块时，必须同时加入 `index.html` 的脚本列表，并保证被依赖的模块先加载（全部是全局脚本，没有模块打包）。

## 数值调整入口

- **全局难度**：`campaign.js` 顶部的 `DIFFICULTY`
  - `enemyCount` 刷怪频率倍率、`enemyHp` / `enemyDamage` 敌人生命与伤害
  - `bossHp` / `bossDamage` 首领生命与伤害
- **动态难度**：`campaign.js` 的 `AdaptiveDirector`
  - 按每波掉血比例与击倒次数累积 `heat ∈ [-1, 1]`
  - 正向加压、负向舒缓；HUD 波次面板显示「威胁 · 状态 ±%」
- **波次基础曲线**：`campaign.js` 的 `CampaignBalance` / `ThreatPacing`
- **特殊波次**：`campaign.js` 的 `WaveTypes`
  - 每个战区随机排出 3–4 波：怪潮（数量压制）、高危（精英集群）、突袭（高速单位）、炮火（远程压制）
  - 每区保底 1 波怪潮 + 1 波高危，种子每局重掷
  - 波次面板显示「侦察 · 怪潮」这类标签，悬停可看完整说明
- **地图随机异常**：`stage-events.js` 的 `anomalies`
  - 每区随机一个整区生效的异常，共 15 种，分「增益 / 风险 / 危险」三档
  - 正面：补给信号、装甲残骸、幸运潮汐；负面：磁暴、地脉震动、沙暴、虚空潮汐、离子雾、流沙带、酸蚀雨
  - 混合：静电风暴、过载电网、海市蜃楼、重力异常、断电区；离子雾会让枪械 12% 哑火
  - 一局五个战区保证正/混与负/混各至少 2 个，首区不出纯负面；HUD 前缀显示档位
  - 进入战区时横幅播报，HUD 常驻显示剩余波次；同一局不重复，无尽塔不启用
- **地图宝箱**：`treasure-sites.js`
  - 每张地图一个随机物资点；开箱奖励按权重抽取：回血、护盾、经验、技能升级、海克斯、临时 Buff
  - 约 7% 触发「满载物资」双奖励；约 18% 是破损军械箱，开箱会引来 5–7 名敌人但奖励更好
  - 箱子颜色区分普通/稀有/危险，开箱位置由本局种子决定，奖励在开箱瞬间才揭晓
- **技能等级上限**：`game.js` 的 `SKILL_LEVEL_CAP_BONUS`
  - 常规技能上限统一 +2（例如连射 6→8、多重弹 4→6）；`max:99` 的成长型牌不受影响
- **战前准备**：`preparations.js` 的 `specs`
  - 选牌刷新、应急锁血、机甲预充、战术补给、海克斯扩容
  - 新增：赏金协议（结算积分 +12/24/36%）、装甲衬板（护甲 +4/8/12）、开局护盾（+1/+2 层）
  - 新增：备用机体（每局复活 +1）、拾荒协议（道具掉落率 +12/24%）
  - 等级与价格走 `MODULE_COSTS`，在补给站「战前准备」页购买，下次出击生效
- **武器配件**：`weapon-attachments.js`
  - 三槽位：枪管 / 弹匣 / 战术模块；每把武器独立装配，收藏永久保存
  - 开局自带标准枪管、标准弹匣、标准握把；其余配件从精英（约 12%）与首领（必掉）掉落
  - 拾取后立即带出局外并写入存档，重复配件折算 80 积分；在「武器调校」里选择武器后点击槽位切换
  - 通用配件：加长/短管/重型/膛线枪管、快拔/扩容/高压/弹鼓、制退器、弹道计算机、穿甲/爆裂模块等
  - 趣味/特殊配件：冷冻、燃烧、连锁弹匣、武器技能核心（Q 冷却 -15%）、无人机挂架、吸能模块
- **基础强化 · 机甲**：`growth.js` 的 `GROWTH_MODULES`
  - 机甲火力（伤害 +5%/级）、机甲续航（变身 +1.2 秒/级）
  - 能量回收（能量获取 +8%/级）、机甲技冷却（-4%/级）
  - 三种机甲通用，存入下次出击的配置快照
- **积分结算**：`game.js` 的 `settle()`
  - 基础收益：击杀 ×1.5、得分 ×6.5%、战区深度 ×85、通关 +500；比旧版约快 30%
  - 赏金协议再乘 1.12 / 1.24 / 1.36；无尽塔结算同样生效
  - 结算报告会单独列出「赏金协议 +N%」
- **Boss 渲染**：`boss-models.js` / `boss-effects.js`
  - 每个 Boss 增加背光剪影、装甲渐变、轮缘光、接触阴影与分件视差；阶段切换用核心辉光/裂纹/蒸汽表达
  - 低画质 `QLEVEL=0` 自动退化为平涂与单层剪影；预警线/冲击环整体透明度已下调
- **小怪特效**：`enemy-effects.js` + `game.js` 的 `drawEnemy`
  - 敌弹按场景统一色相、拖尾缩短；死亡溶解碎片量与白色闪光大幅下降；普通怪不再叠加彩色轮廓光

## 地图机制

- **第一区 · 落日废土**
  - 地表持续沙暴：每秒 2 点侵蚀伤害 + 视野压缩，庇护点内免疫，逼玩家下井
  - 地下箱庭：卸料厅（16 只）→ 泵房（18 只）→ 冷却塔（20 只）→ 仓储环廊（18 只）→ 排风配电室（高血量小 Boss）
  - 四间战斗厅占满四象限，门按厅室顺序解锁；进入地下后普通波次冻结、升降机锁定
  - 小 Boss 击破并启动排风后才能返回地表，沙暴同时停止
- **第二区 · 霓虹雨夜**：引雷塔未接通前周期性雷击预警；接通后转为三道友方落雷
- **第三区 · 冰封矿场**：断崖阻断矿井层，启动地热架桥阀展开冰桥后才能到对岸
- **第四区 · 熔岩工厂**：熔岩水位 0–3 级持续上涨，开启冷却阀清池并进入冷却
- **第五区 · 虚空核心**：相位锚未校准前周期性虚空塌陷，首次跃迁后停止
- **站点支援**：在支援信标半径 90 内停留 1.7 秒呼叫，12 秒后抵达；地表与地下都有信标
  - 6 种随机支援：哨戒炮、定点炮击、僚机护航、维修无人机、护盾发生器、电磁脉冲
  - 3 个信标种类互不相同，之后进入 32–44 秒冷却；支援强度随战区提升

相关入口：
- `field-maps.js`：`dungeonActive()/dungeonInfo()/tickDungeon()`、`liftLocked()`、`bridgeOpen()/cliffBlocked()`
- `sector-climate.js`：`surfaceHazard()/stormStatus()`、`facilityStatus()`、`supportStatus()/readySupport()/consumeSupport()`
- `stage-events.js`：`anomalies`（15 种）、`missChance()`（离子雾哑火）、`enemySpeedMul()`
- `treasure-sites.js`：`prepare()/interact()`、`marker()/label()`、奖励表 `rewards` 与 `buffPool`
- `weapon-attachments.js`：`equipped()/cycle()/collect()/drop()`、`applyStats()`、`weaponSkillCooldown()`
- `game.js`：`updateFieldHazards()`、`applySupport()`、`supportStrike()`、`reformWaveEnemies()`（换层清场）

## 选卡交互

- 卡片入场按 1–5 张错峰淡入；点选后 160ms 内锁定输入，选中卡高亮 + 勾选、其余变暗，再结算
- 替换槽位与海克斯已持有状态有独立徽标；`prefers-reduced-motion` 下只保留颜色变化
- 刷新、跳过、取消、升彩在选中动效期间会被安全忽略
- **海克斯选牌次数**：`hexes.js` 的 `baseMilestones` 与 `extraMilestones`
  - 默认每局 4 次；补给站「海克斯扩容」每级 +1 次，最多 6 次
- **海克斯/技能独立重掷**：`hexes.js` 的 `hexRefreshMax/hexRefreshLeft` 与 `talents.js`
  - 每张候选牌右上角有独立 ↻，只替换这一张，其余牌保持不动；按 R 重掷当前聚焦的牌
  - 海克斯每局默认 1 次重掷；「重掷协议」+1 次、「预案仓储」+2 次
  - 海克斯优先消耗海克斯重掷，用完后可消耗战前准备的「选牌刷新」；普通技能牌直接消耗选牌刷新
  - 至少出现一张新牌才消耗次数
- **海克斯卡池**：`hexes.js` 的 `cards` 与 `tags`
  - 新增 12 张填充牌（缓冲、侦测、稳压、黄铜弹壳、反应装甲、弹道计算、收敛火力等）
  - 过强的纯数值/召唤牌已整体下调一档；新卡需要同时补 tag
- **海克斯卡牌**：`hexes.js` 的 `cards` 与 `tags`（新卡需要同时补 tag）
- **技能槽上限**：`growth.js` 的 `BASE_SKILL_CAPACITY` 与「技能扩容」模块

## 发布

`main` 分支只保存 `dist/` 源码；GitHub Pages 从 `gh-pages` 分支根目录发布。更新线上版本时把 `dist/` 的内容同步到 `gh-pages`。

## 注意

- `game.js` 体积较大，改动前先确认相关数据表位置（武器 183 行、皮肤 532 行、Boss 5564 行附近）。
- 所有脚本共享全局作用域，新增全局名称前先搜索是否重名。
- 触屏与桌面共用同一套 DOM，HUD 尺寸通过 `terminal.css` 里的 `@media(pointer:coarse)` 调整。
- 竖屏 HUD 会把「状态 / 波次」改为双列并让出右上角按钮与地图；短横屏隐藏叙事行，避免遮挡战场。
- 手机浏览器顶部地址栏/底部导航属于浏览器外壳，网页无法直接隐藏。项目已带 `manifest.webmanifest` + `sw.js`：用系统浏览器的「添加到主屏幕 / 安装应用」从桌面启动可进入独立窗口；游戏内「设置 → 无地址栏运行」有分平台说明。
